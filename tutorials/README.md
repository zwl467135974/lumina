# Lumina 全栈大师进阶之路

> **一套配合 Lumina 项目源码的实战教学体系**——不讲基础语法，从"会语言不懂框架"带到"全栈 + AI 双修"。

---

## 这套教程是给谁看的

**你应该具备**：

- ✅ 能看懂 Java 的类、接口、泛型、lambda（不需要精通，能读懂就行）
- ✅ 能看懂 JavaScript / TypeScript 的基本语法
- ✅ 用过命令行，知道怎么装软件、配环境变量
- ✅ 有一个 LLM API Key（智谱 GLM / 阿里 DashScope / OpenAI 均可）

**你不需要具备**：

- ❌ 不需要了解 Spring / Spring Boot / MyBatis
- ❌ 不需要了解 Vue / React / 前端框架
- ❌ 不需要了解 Redis / Docker / 微服务
- ❌ 不需要了解 AI / 大模型 / Agent / RAG 是什么

> 如果你在上述"不需要"里看到了自己不懂的词，恭喜——这套教程就是为你写的。

---

## 学完能达到什么水平

| 阶段 | 目标 | 能做什么 |
|------|------|----------|
| **第一阶** | 能上手 | 把项目跑起来，看懂代码结构，能做简单修改 |
| **第二阶** | 能开发 | 理解项目设计理念，能独立开发新功能，中级开发水平 |
| **第三阶** | 懂原理 | 深入底层原理，面试能讲清"为什么"，理论+实践双修 |
| **AI 专项** | 懂 AI | 从零理解 AI Agent 全链路，掌握 Lumina 16 大核心能力 |

最终你将成为：**既懂企业级 Java 全栈开发，又懂 AI Agent 架构的稀缺人才**。

## 教程结构总览

### 🤝 第零阶：AI 协作方法论（1 篇）— 本项目的独有教学资产

[如何用 AI 开发本项目：纲领、技能包与检查清单](stage-0-ai-collaboration/01-how-this-project-is-built-with-ai.md)

本项目绝大部分代码由 AI 编写、人类定向完成。这一篇拆解支撑这种开发方式的方法论资产——AGENTS.md 纲领（四镜像）、13 个按需加载的定制技能包、事故驱动的前置检查清单、自进化机制——以及**五步迁移指南**，可完整复制到任何团队的技术栈。**不止学框架，学"怎么用 AI 做工程"。**

### 📘 第一阶：技术栈基础（17 篇）— "能上手"

[→ 查看第一阶导读](stage-1-foundation/README.md)

用类比和最小示例讲清每个技术栈"是什么、怎么用"，每篇都对照 Lumina 项目真实代码。

**后端基础**（01-10）：Maven 多模块 → Spring Boot → MyBatis-Plus → Redis → Flyway

**前端基础**（11-17）：Vue 3 → Element Plus → Pinia/Router → TypeScript/Vite → Axios/SSE → 跑起项目

### 📗 第二阶：项目实战应用（15 篇）— "能开发"

[→ 查看第二阶导读](stage-2-application/README.md)

理解 Lumina **为什么这么设计**：分层架构、异常体系、权限 RBAC、多租户、JWT 认证……每篇都回答"为什么"。

两篇核心实战带你从零写一个完整功能模块（后端 + 前端），每一步对照项目现有模式。

### 📕 第三阶：原理深潜（15 篇）— "八股文大师"

[→ 查看第三阶导读](stage-3-mastery/README.md)

深入底层：Spring IoC 源码、AOP 代理、事务传播、MyBatis 拦截器、ThreadLocal 上下文、分布式锁、响应式编程、工作流引擎……

每篇以"面试题"开篇，跟到 Lumina 代码 + 框架源码，最后给面试速查表（40 考点）。

### 🤖 第四阶：AI/Agent 专项（32 篇）— Lumina 核心卖点

[→ 查看 AI 专项导读](stage-4-ai-agent/README.md)

**Lumina 是 AI Agent 平台，AI 是最大的教学模块。** 按 10 个子模块组织：

| 子模块 | 篇数 | 你将学会 |
|--------|------|----------|
| **A 基础认知** | 5 | LLM 是什么、Prompt 工程、从 Chatbot 到 Agent |
| **B Agent 核心** | 5 | ReAct 循环、Plan-Execute、AgentScope SDK 封装 |
| **C 工具系统** | 5 | Function Calling、@AgentTool 注解、MCP 协议 |
| **D RAG 知识库** | 8 | 向量检索、混合检索、Rerank、OCR、租户隔离 |
| **E 记忆对话** | 4 | 短期记忆、长期记忆、多轮上下文 |
| **F 输出交互** | 4 | 流式 SSE、多模态、OpenAI 兼容、安全防护 |
| **G 成本管控** | 4 | 模型定价、Token 计费、预算、限流并发 |
| **H 质量保障** | 4 | 评估框架、4 种评分器、A/B 测试、回归 |
| **I 编排自动化** | 5 | 工作流编排、6 种节点、Flowable、人工审批、Cron |
| **J 集成全景** | 3 | Webhook、代码沙箱、AI 架构总结 |

## 重要约定

### 教学即代码审查
写教学 = 逐行读代码。如果发现项目代码有问题（命名不规范、潜在 bug、注释缺失），**会先修正代码再写入教程**。每篇文档结尾附修正清单。

### 代码引用
引用项目代码时给完整路径，例如：
> `lumina-modules/lumina-business-agent/.../AgentController.java:84`

你可以直接打开对应文件对照阅读。

### 不重复造轮子
这套教程专注于**教会你"为什么"和"怎么用"**。需要查 API 细节时，指向已有的 `docs/` 开发者文档。
