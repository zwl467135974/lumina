# 第五阶：攻防与规模化实战（面试硬核篇）

> **8 篇 · 每篇 15-25 分钟 · 前置：第三阶原理 + AI 专项 B 模块**
>
> 前四阶教你"把系统做对"，这一阶教你回答三个更狠的问题：
> **有人攻击它怎么办？环境变了怎么办？你自己知道它哪里烂吗？**
>
> 本阶所有案例都来自 Lumina 项目的真实攻防与事故（v3.11–v3.12.1 的安全评审与修复），
> 每个设计决策都能在源码和 ADR 里找到对应——这不是八股文，是复盘文。

---

## 这阶和第三阶（原理）有什么不同

第三阶讲框架原理（Spring 怎么实现 AOP），是**向下**挖；这一阶讲工程判断（为什么守卫不能有 allow 臂、为什么判活失败按活着算），是**向难**挖——挖的是同一份代码里那些"文档不会告诉你为什么"的决定。

适合：准备后端/AI 平台方向面试的同学、接手 Lumina 二次开发的工程师、想看"安全评审到底评什么"的读者。

## 学习建议

1. **顺序读**：S01/S02（构造）→ S03-S06（攻防）→ S07（架构）→ S08（元认知），暗线是"做对 → 假设会错 → 让别人做对 → 知道边界"。
2. **对照源码**：每篇头部标了真实代码位置，遇到"为什么这么设计"就跳进去看——本阶的价值一半在"项目里真有这个东西"。
3. **自测题当面试预演**：每篇的自测题就是面试官的真实问法，先自己答，再展开对照。
4. 学完 S08 做那个练习：给自己的项目（或 Lumina）写一页"找茬文档"——这是本阶的毕业考试。
