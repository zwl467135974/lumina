## 这节解决什么问题

有两个版本的 Prompt（或两个模型），不知道哪个效果好。**A/B 测试**：把流量按比例分给两个版本，对比效果。

---

## A/B 测试原理

```
用户请求进来
  ↓
按权重分流（如 50% A : 50% B）
  ├── 50% → 版本 A（旧 Prompt）
  └── 50% → 版本 B（新 Prompt）
  ↓
同会话粘滞（同一个用户总是走同一版本，避免体验不一致）
  ↓
收集结果 → 对比两个版本的效果指标
```

## 小结

| 概念 | 一句话记忆 |
|------|-----------|
| A/B 测试 | 流量按比例分给两个版本对比 |
| 权重分流 | 50%:50% 或其他比例 |
| 同会话粘滞 | 同一用户始终走同一版本 |
| 效果对比 | 两个版本的评分/通过率对比 |
