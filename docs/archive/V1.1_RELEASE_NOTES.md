# Lumina v1.1 发布说明

**发布日期**: 2026-07-01
**版本**: v1.1（基于 v1.0 质量增强与可观测性迭代）

---

## 一、新增功能

### 1. 会话与记忆管理（4.2）
- **多轮对话**：以 `conversationId` 维度持久化对话上下文，Agent 可读取历史记忆实现多轮交互
- **双轨记忆**：Redis 热记忆（MemoryManager，上下文窗口 20 条）+ DB 冷存储（lumina_message 表，永久）
- **历史回放**：`GET /api/v1/conversations/{uuid}/messages` 分页查询历史消息
- **Token 用量**：记录每次 assistant 回复的 token 消耗与耗时
- **前端**：AgentChat 会话列表侧栏 + 历史消息气泡 + 流式打字机
- **数据表**：lumina_conversation + lumina_message（Flyway V3）

### 2. 工具调用可观测（4.5）
- **调用记录**：ToolInvocationRecord（入参/出参/耗时/成功/错误）
- **统计**：ToolInvocationRecorder（按工具名：次数/成功率/耗时分布 max/min/avg，内存环形缓冲 1000 条）
- **熔断器**：ToolCircuitBreaker（CLOSED→OPEN→HALF_OPEN，阈值 5 次连续失败，冷却 60s）
- **监控 API**：`/api/v1/tools`（stats/invocations/breakers）
- **前端**：`/monitor/tools` 工具监控页

### 3. 审计日志（5.3）
- **声明式审计**：`@Audit(module, action, description)` 注解 + AOP 切面自动采集
- **事件驱动**：framework 发 AuditEvent → base 监听写库（解耦）
- **记录内容**：操作人/模块/动作/目标/HTTP/状态/耗时
- **查询**：`GET /api/v1/audit-logs`（按模块/动作/用户过滤）
- **已标注**：19 个关键方法（auth/user/role/tenant/permission/agent 的增删改+登录登出）
- **数据表**：lumina_audit_log（Flyway V4）

### 4. 网关限流（6.3）
- **RateLimitGlobalFilter**：固定窗口算法，全局(100/s) + 单 IP(20/s) 双维度
- **超限响应**：429 + JSON 错误信息
- **配置**：`lumina.gateway.rate-limit.global` / `per-ip`

### 5. API 版本策略（6.1）
- **@DeprecatedApi** 注解：标注废弃端点
- **响应头**：`Deprecation: true` + `Sunset: <date>` + `Link: <replacement>; rel="successor-version"`
- **自动注入**：ApiDeprecationInterceptor（所有 MVC 服务自动生效）

### 6. Micrometer 监控指标（5.2）
- **埋点**：`agent.execution.duration` + `tool.invocation.duration`（Timer，含 type/result tag）
- **端点**：`/actuator/prometheus`（Prometheus 文本格式）
- **可视化**：docker-compose 集成 Prometheus(:9090) + Grafana(:3001)

### 7. 前端体验增强（7）
- **工具监控页**：`/monitor/tools`
- **暗色主题**：AppHeader 一键切换（localStorage 持久化）

## 三、关键 API 速查

### 会话管理
```
POST   /api/v1/conversations?agentId=&title=     创建会话
GET    /api/v1/conversations?agentId=             会话列表
GET    /api/v1/conversations/{uuid}               会话详情
DELETE /api/v1/conversations/{uuid}               删除会话
GET    /api/v1/conversations/{uuid}/messages      历史消息
POST   /api/v1/agents/{id}/execute/stream?task=&conversationId=  流式执行（多轮）
```

### 监控
```
GET    /api/v1/tools/stats                        工具调用统计
GET    /api/v1/tools/invocations?limit=50         最近调用记录
GET    /api/v1/tools/breakers                     熔断器状态
GET    /api/v1/audit-logs?module=&action=&userId= 审计日志
GET    /actuator/prometheus                       Prometheus 指标
GET    /actuator/health                           健康检查
```

## 四、部署：监控栈

```bash
# 启动监控栈（按需）
docker compose up -d prometheus grafana

# 启动业务服务（Prometheus 自动抓取）
docker compose up -d gateway business-base agent-service
```

| 服务 | 地址 | 说明 |
|------|------|------|
| Prometheus | http://localhost:9090 | 指标抓取/存储（保留 7 天） |
| Grafana | http://localhost:3001 | 仪表盘（admin/admin） |

Grafana 添加数据源 `http://prometheus:9090`，即可建仪表盘。
