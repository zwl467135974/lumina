# 快速开始

## 环境要求

- **JDK 21+**
- **MySQL 8.0+**（运行在 localhost:3306）
- **Redis 7.0+**（运行在 localhost:6379）
- **Maven 3.9+**
- **Node.js 20+** + **pnpm**

## 1. 数据库准备

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS lumina_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
```

首次启动时 Flyway 自动迁移（V1–V12），无需手动建表。

## 2. 配置 API Key

```bash
# Windows PowerShell
$env:LLM_API_KEY="your-api-key"

# Linux/Mac
export LLM_API_KEY="your-api-key"
```

## 3. 启动后端

```bash
# 启动 base 服务（端口 8082，自动执行 Flyway 迁移）
mvn spring-boot:run -pl lumina-modules/lumina-business-base

# 启动 agent 服务（端口 8081）
mvn spring-boot:run -pl lumina-modules/lumina-business-agent

# 启动网关（端口 8080）
mvn spring-boot:run -pl lumina-gateway
```

## 4. 启动前端

```bash
cd lumina-frontend
pnpm install
pnpm dev
```

访问 http://localhost:3000

## 5. 登录

- 用户名：`admin`
- 密码：`admin123`
- 租户：`0`（系统租户）

## 6. 创建第一个 Agent

1. 进入 **Agent 管理** → **新建**
2. 名称：`我的助手`，类型：`assistant`
3. 打开 Agent → 在 **对话执行** 面板开始聊天

## 端口对照

| 服务 | 端口 |
|------|------|
| 前端（开发） | 3000 |
| 网关 | 8080 |
| Agent 服务 | 8081 |
| Base 服务 | 8082 |
| MySQL | 3306 |
| Redis | 6379 |

## Docker Compose 一键启动

```bash
docker-compose up -d
```
