# 快速开始

Lumina 提供两种启动方式，**推荐先用 standalone 单体模式体验**（5 分钟、只需 MySQL+Redis），熟悉后再切微服务模式（生产部署）。

---

## 方式一：standalone 单体模式（推荐体验）

只需 **MySQL 8 + Redis 7**，无需 Nacos / RocketMQ / 独立 Gateway 进程。

### 环境要求

- **Docker** + Docker Compose（最简单）
- 或 **JDK 21+** + **Maven 3.9+** + MySQL + Redis

### 一键启动（Docker Compose）

```bash
# 在项目根目录
export LLM_API_KEY=your-api-key   # 必填，智谱 GLM / 阿里 DashScope 等
docker compose -f docker-compose-standalone.yml up
```

启动后访问：
- 前端（如启用）：http://localhost:3000
- API Gateway：http://localhost:8080
- 健康检查：http://localhost:8080/actuator/health

### 本地开发启动（不用 Docker）

```bash
# 1. 起 MySQL + Redis（本机或容器均可）
# 2. 建库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS lumina_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"

# 3. 设 API Key
export LLM_API_KEY=your-api-key

# 4. 启动 standalone（合并 base+agent+notification 为单进程）
mvn -pl lumina-standalone -am package -DskipTests
java -jar lumina-standalone/target/lumina-standalone-*.jar
```

standalone 默认端口 **8080**，Flyway 启动时自动建表（V1–V49+）。

详见 [`部署指南-standalone`](deployment/standalone部署.md)。

---

## 方式二：微服务模式（推荐生产）

完整微服务架构，含 Gateway / Base / Agent 三服务 + Nacos 服务发现与配置中心 + RocketMQ 异步消息。

### 环境要求

- **JDK 21+**
- **MySQL 8.0+**（localhost:3306）
- **Redis 7.0+**（localhost:6379）
- **Nacos 3.1.1+**（localhost:8848）— **必装**，微服务模式的服务发现与配置中心
- **Maven 3.9+**
- **Node.js 20+** + **pnpm**（前端）
- 可选：RocketMQ（异步任务/审计/通知；不装时各模块自动降级同步处理）

### 1. 启动 Nacos

```bash
wget https://github.com/alibaba/nacos/releases/download/3.1.1/nacos-server-3.1.1.zip
unzip nacos-server-3.1.1.zip && cd nacos/bin && ./startup.sh -m standalone
```

访问 http://localhost:8848/nacos（默认 nacos/nacos），把 `nacos-config/*.yaml` 三个文件导入对应 Data ID：
- `lumina-gateway.yaml`
- `lumina-business-base.yaml`
- `lumina-agent-service.yaml`

### 2. 数据库准备

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS lumina_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
```

首次启动 base 服务时 Flyway 自动迁移（V1–V49+），无需手动建表。

### 3. 配置 API Key

```bash
# Windows PowerShell
$env:LLM_API_KEY="your-api-key"

# Linux/Mac
export LLM_API_KEY="your-api-key"
```

### 4. 启动后端（三个服务）

```bash
# 启动 base 服务（端口 8082，自动执行 Flyway 迁移）
mvn spring-boot:run -pl lumina-modules/lumina-business-base

# 启动 agent 服务（端口 8081）
mvn spring-boot:run -pl lumina-modules/lumina-business-agent

# 启动网关（端口 8080）
mvn spring-boot:run -pl lumina-gateway
```

### 5. 启动前端

```bash
cd lumina-frontend
pnpm install
pnpm dev
```

访问 http://localhost:3000

### 6. 登录

- 用户名：`admin`
- 密码：`admin123`
- 租户：`0`（系统租户）

### 7. 创建第一个 Agent

1. 进入 **Agent 管理** → **新建**
2. 名称：`我的助手`，类型：`assistant`
3. 打开 Agent → 在 **对话执行** 面板开始聊天

### 端口对照

| 服务 | 端口 |
|------|------|
| 前端（开发） | 3000 |
| 网关 / standalone | 8080 |
| Agent 服务（微服务模式） | 8081 |
| Base 服务（微服务模式） | 8082 |
| MySQL | 3306 |
| Redis | 6379 |
| Nacos | 8848 |
