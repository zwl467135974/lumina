## 执行计划

### P0 — 核心可用性（必须）

#### P0-1: 模型管理
- LLM 模型注册表（provider/modelName/baseUrl/默认参数）
- API Key 集中管理（加密存储、脱敏显示、轮换）
- 连通性测试（Test Connection）
- Agent 表单改为引用 model_id
- 用量统计（按模型维度）

#### P0-2: Agent 表单补全
- topP / frequencyPenalty / presencePenalty 参数
- 工具参数配置面板（非简单 checkbox）
- RAG 知识库挂载集成（Agent 表单内选择 KB）
- 限流配置（rateLimit / maxConcurrent）

### P1 — 用户体验（重要）

#### P1-1: 个人中心
- 个人资料（头像/昵称/邮箱/手机）
- 修改密码
- 偏好设置（默认主题/语言/通知偏好）

#### P1-2: 工作流节点扩展
- HTTP 请求节点
- 延迟/定时节点
- 代码/脚本节点
- Start/End 节点
- 独立 LLM 调用节点

#### P1-3: 通知中心
- 通知列表（已读/未读/筛选）
- 实时推送（WebSocket/SSE）
- 告警渠道配置（邮件/钉钉/飞书/Webhook）
- 预算告警闭环

### P2 — 运维完善（后续）

- 菜单管理
- 字典管理
- 在线用户管理
- 服务器监控
- 定时任务管理
- API 文档入口

### 遗留清理
- 删除孤儿文件 `views/error/403.vue`
- 删除遗留文件 `views/knowledge-base/index.vue`
