## 验收标准

每个交付物必须满足：
1. **有代码**：测试代码提交到 git，编译通过
2. **有执行证据**：`mvn test` 输出显示 Tests run: N, Failures: 0
3. **有文档更新**：AGENTS.md 或技能包更新对应规范
