## 阶段 1：关键路径集成测试（优先级最高）

### 理由
本次审计发现的 11 个 bug 全部不是测试捕获的。每修一个 bug 就该有一个回归测试，否则改 A 坏 B 的风险永远存在。

### 交付物

| # | 测试类 | 验证内容 | 覆盖的历史 bug |
|---|--------|---------|---------------|
| 1.1 | `AgentExecutionIntegrationTest` | 同步执行后 task 表有 token/modelName/provider | Token 不持久化 (P0) |
| 1.2 | `AgentExecutionIntegrationTest` | rateLimit=N 时第 N+1 次返回 429 | 限流不生效 |
| 1.3 | `AgentExecutionIntegrationTest` | maxConcurrent=1 时第 2 个并发被拒 | 并发控制新增 |
| 1.4 | `AgentExecutionIntegrationTest` | 多模态异步执行后 task 表有 token | 多模态 token 丢失 (P1) |
| 1.5 | `AgentPermissionIntegrationTest` | TENANT_USER 角色不能创建 Agent | Controller 无权限 (P0) |
| 1.6 | `AgentPermissionIntegrationTest` | 无 token 访问返回 401 | 认证基础 |
| 1.7 | `WorkflowResumeIntegrationTest` | PAUSED → resume 后上下文变量存在 | 工作流丢上下文 (P0) |
| 1.8 | `BudgetEnforcementIntegrationTest` | 超预算执行返回 BUDGET_EXCEEDED | 预算链路 |
| 1.9 | `BudgetEnforcementIntegrationTest` | 阈值告警只发一次（去重） | 告警轰炸 (P2) |
| 1.10 | `KnowledgeBaseIsolationIntegrationTest` | Agent 只检索挂载的 KB 内容 | RAG 隔离 |
| 1.11 | `CostCalculationIntegrationTest` | 成本按正确模型价格计算 | model/default 回退 |

### 技术方案
- 基于现有 `BaseIntegrationTest`（@SpringBootTest + test profile + 真实 MySQL）
- 每个 @Test 方法自包含数据（创建→验证→@Transactional 回滚）
- 使用 GLM-4-Flash（免费模型）做真实 LLM 调用验证 token

## 阶段 2：安全加固（防越权/防注入/防御纵深）

### 理由
当前安全仅依赖 TenantLineInterceptor 的 SQL 自动改写 + JWT 认证。无显式权限校验（刚补的 @RequirePermission 未经测试验证），无防御纵深。

### 交付物

| # | 内容 | 说明 |
|---|------|------|
| 2.1 | 权限拦截器集成测试 | 验证 @RequirePermission 正确拦截无权限请求 |
| 2.2 | 租户越权测试 | A 租户用户不能查/改 B 租户的 Agent/KB/Task |
| 2.3 | 文件服务租户隔离测试 | 跨租户 fileUuid 访问返回 404 |
| 2.4 | API Token 权限范围验证 | API Token 只能调用 OpenAI 兼容端点，不能调管理 API |
| 2.5 | Prompt 注入防护验证 | promptInjectionFilter 正确拦截恶意输入 |

## 验收标准

每个交付物必须满足：
1. **有代码**：测试代码提交到 git，编译通过
2. **有执行证据**：`mvn test` 输出显示 Tests run: N, Failures: 0
3. **有文档更新**：AGENTS.md 或技能包更新对应规范

## 不做（明确排除）

- K8s/Helm 部署验证（已有 docker-compose 验证足够）
