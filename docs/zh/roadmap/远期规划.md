## ✅ H. OCR / 扫描件 PDF 支持（已完成）

**难度**: ⭐⭐⭐⭐
**状态**: ✅ 已完成（commit `5ec0281` + 审计修复 `52a5167`）

### 已实现内容
- **OcrProvider 接口** + `@ConditionalOnProperty` 模式（与 Reranker 一致）
- **5 个 Provider**: Noop（默认零依赖）/ Baidu / Tencent / Google / Alibaba
- **PdfOcrProcessor**: PDFBox 渲染 → 逐页 OCR → 文本拼接
- **三入口集成**: RAG 异步入库 / RAG 同步入库 / 多模态对话
- **官方签名算法**: 百度 access_token / 腾讯 TC3-HMAC-SHA256 / 阿里 ACS3-HMAC-SHA256 / Google API Key

### 使用方式
```yaml
lumina.rag.reader.ocr:
  enabled: true
  provider: tencent          # none/baidu/tencent/google/alibaba
  api-key: ${OCR_API_KEY}
  secret-key: ${OCR_SECRET}  # 百度/腾讯需要双 Key
```

## ✅ I. Reflective Memory（自进化记忆）— 简单版已完成

**难度**: ⭐⭐⭐⭐⭐
**状态**: ✅ 简单版已完成；复杂版冻结（ROI 低）

### ✅ 简单版已完成
- **数据模型**: `lumina_long_term_memory` 表（V33 迁移）
- **ReflectiveMemoryService**: 对话后异步调用 LLM 提取 ≤5 条关键事实
- **去重**: content 完全相同的跳过（简单文本匹配）
- **注入**: `buildContextMessages` 加载长期记忆注入到上下文最前面（system 消息）
- **配置**: `lumina.agent.memory.reflective.enabled` 默认关闭

### ❄️ 复杂版冻结（简单版够用，后续有真实需求再启动）
- 定时整合 / 评分淘汰 / 语义去重 / 前端管理 / 隐私控制

## ✅ J. Code Interpreter / 沙箱执行（已完成）

**难度**: ⭐⭐⭐⭐⭐⭐
**状态**: ✅ 已完成（Docker 版 + 增强版，commit `0c29f5f` + `d75701e`）

### 已实现内容
- **双模式执行**：process（本地进程，默认）/ docker（容器隔离，推荐）
- **Docker 容器池**：Testcontainers `GenericContainer` + `ContainerPool`（按 image 缓存常驻容器，空闲超时销毁，复用 13.8x 提速）
- **资源限制**：memory/CPU（NanoCpus）/网络禁用/超时销毁
- **依赖管理**：内联声明 `# pip: pandas,numpy` / `// npm: lodash` + requirements.txt/package.json
- **工具注册**：`@AgentTool(name="code.execute")` 注解，Agent ReAct 循环可调用
- **语言**：python / javascript

### 配置
```yaml
lumina.agent.code-interpreter:
  enabled: true
  mode: docker              # process / docker
  python-image: python:3.11-slim
  node-image: node:20-slim
  memory-limit-mb: 256
  cpu-limit: 1.0
  network-disabled: true
  pool-size: 2
```
